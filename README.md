# Power Platform Toolkit

An open-source learning project for Microsoft Power Apps, Power Fx, and Power Automate.

## Goals

- Learn Power Fx formulas through practical examples.
- Document Canvas App design patterns.
- Explore common Power Automate workflows.
- Share troubleshooting tips and beginner-friendly guides.

## Planned Examples

- Form validation
- Search and filter galleries
- Collections and variables
- Error handling
- Approval workflow concepts

## Project Status

This project is in its initial development stage. Examples and documentation will be added and tested incrementally.
